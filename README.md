# JPEG

JPEG is an NFT launchpad where each uploaded image becomes a one-of-one NFT with a real Pump.fun coin attached.

**Live site:** https://mintjpeg.com

## How it works

- **Built-in wallets** — each account gets its own encrypted Solana wallet for deposits, minting, buying, and selling.
- **Minting** — upload artwork, choose a unique name and ticker, and launch its attached Pump.fun coin for a flat 0.1 SOL fee.
- **One of one** — only one active NFT can use a name. Burning it releases the name.
- **Trading** — owners can list NFTs or accept offers paid directly in SOL.
- **On-chain proof** — launches, transfers, and sales link to Solscan.

## Tech

TypeScript · React 19 · TanStack Start · Tailwind CSS v4 · Solana · Pump.fun

## Development

Requires Node.js 18+.

```sh
npm install
npm run dev
```

The development server runs at `http://localhost:8080`.
